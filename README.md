# 🚀 AI Code Transpiler (Gemini API)

A full-stack AI-powered code translation application built with **ReactJS** and **Python**. It leverages Google's Gemini API to accurately convert functional source code across **Java, C#, and Python**.

This tool focuses on syntax preservation, structural mapping, and object-oriented programming (OOP) principles when translating clean code bases.

---

## ✨ Features

- **Supported Languages:** Cross-translation between Java, C#, and Python.
- **AI-Driven Translation:** Uses Google Gemini API for intelligent code refactoring and syntax mapping.
- **Strict Input Validation:** Designed to process valid code structures to ensure reliable and compilable output.
- **Interactive UI:** Web-based interface built with ReactJS for code input and real-time translation viewing.

---

## 🛠️ Tech Stack

- **Frontend:** ReactJS, JavaScript (ES6+), HTML5/CSS3
- **Backend:** Python (FastAPI)
- **AI Integration:** Google Gemini API
- **Version Control:** Git & GitHub
